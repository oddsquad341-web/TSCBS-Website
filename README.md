# TSCBS Website — Ladies Corner Store

A complete, production-ready e-commerce website for TSCBS — a ladies corner retail store selling jewellery, bangles, cosmetics, hair accessories, bindis, skincare, and combo sets.

## Pages Included

| Page | File | Description |
|------|------|-------------|
| Homepage | `index.html` | Hero, categories, products, offers, testimonials |
| Shop All | `pages/shop.html` | Full product listing with filters & sort |
| New Arrivals | `pages/new-arrivals.html` | Latest additions |
| Cart | `pages/cart.html` | Cart with coupon code support |
| Contact | `pages/contact.html` | Contact form + store info |

## Structure

```
TSCBS-Website/
├── index.html          # Homepage
├── css/
│   └── style.css       # Full design system
├── js/
│   └── main.js         # Cart, wishlist, toast, scroll reveal
├── pages/
│   ├── shop.html
│   ├── new-arrivals.html
│   ├── cart.html
│   └── contact.html
└── images/             # Add product images here
```

## Features
- 🛒 Cart with localStorage persistence
- ♡ Wishlist functionality
- 🔍 Search bar
- 🎟 Coupon code support (try `TSCBS10`)
- 📱 Fully responsive (mobile-first)
- 💬 WhatsApp floating button
- ✨ Scroll reveal animations
- 🎨 Rose gold & ivory design theme

## Design System
- **Display font**: Cormorant Garamond (elegant serif)
- **Body font**: DM Sans (clean, readable)
- **Primary color**: `#c8506a` (rose)
- **Accent**: `#c9984a` (gold)
- **Background**: `#faf7f2` (ivory)

## To Add More Pages
Copy any existing page in `/pages/` and update the content. All pages share `css/style.css` and `js/main.js`.

## WhatsApp Integration
Replace `919999999999` in all files with your actual WhatsApp number.
